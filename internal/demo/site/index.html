A fast page

This page does nothing wrong. It is the control.

What this page does Small HTML, one stylesheet, no images, no blocking script, no layout shift. Every metric should land in the good band.

Real User Monitoring measures what visitors actually experienced, rather than what a synthetic test measured on a fast machine in a data centre. The five Core Web Vitals collected here are LCP, INP, CLS, FCP, and TTFB.

Click through the other pages in the navigation. Each one is broken in a specific, deliberate way, so the dashboard shows all three status bands instead of a wall of green.

This button responds immediately, so it produces a small INP value.

Every page here loads /b.js, the 942-byte beacon, from this same server. Measurements are sent once, when you leave the page or switch tabs, so click through a few pages and then open the dashboard.
